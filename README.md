# Dedsafio 4 Remake

Este proyecto lo hice para aprender a hacer shaders, y ya que mi post lo vio mucha gente en Twitter, decidí hacer el mod público y además portearlo a Fabric y NeoForge 1.21.1 que las usa más gente.

El mod esta hecho 100% con shaders vanilla, no usa ninguna textura/modelo ni necesita un shaderpack.

## Uso

Debe estar instalado en **servidor** y **cliente**
Es un mod simple, solo puede ser ejecutado por OP.

- `/dedsafio start`
- `/dedsafio stop`
- `/dedsafio reset`
